# Synchronous Buck Converter

Custom synchronous buck converter PCB designed in KiCad and simulated in LTspice.

## Specifications

- Input voltage: 12 V
- Output voltage: 5-9 V
- Maximum output current: 5 A
- Topology: synchronous buck
- PCB: 2-layer
- Tools: KiCad, LTspice

## Project Overview

This project was created to learn PCB design and power electronics through the design, simulation, layout, assembly, and testing of a synchronous buck converter.

## Design Process

1. Defined electrical requirements
2. Designed the power stage
3. Simulated the circuit in LTspice
4. Created the schematic in KiCad. (credit: GreatScott!)
5. Selected components and footprints
6. Designed the PCB layout
7. Ran ERC and DRC
8. Ordered the PCB
9. Currently assembly and testing voltage regulation, ripple, and efficiency
